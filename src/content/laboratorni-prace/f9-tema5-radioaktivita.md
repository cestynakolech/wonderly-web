# Laboratorní práce: Detekce radioaktivního záření

## Podtéma: Pozorování a měření ionizujícího záření

**Cíl:** Prakticky pozorovat **ionizující záření** pomocí detektoru a ověřit jeho **vlastnosti** (průchodnost, absorpce).

---

## 1. Úvod

Některé prvky jsou **radioaktivní** — samovolně vyzařují energii v podobě záření (alfa, beta, gama). Ačkoli je to nebezpečné, můžeme je detekovat a měřit jejich intenzitu. V těchto pokusech budeme pracovat s **bezpečnými, slabými zdroji** a moderními detektory.

Během experimentu budete:
- **Detekovat** radioaktivní záření
- **Měřit** intenzitu vyzářeného záření
- **Testovat** průchodnost různých materiálů
- **Ověřovat** zákon poklesu aktivity

---

## 2. Pomůcky

**Základní pomůcky:**
- **Detektor radioaktivního záření** (Geiger-Müllerova trubice, scintilační detektor nebo smartphone aplikace s dostupným čidlem)
- **Slabý radioaktivní zdroj** (např. staré hodiny se svítící číslicí ze 60. let — obsahují Ra-226, nebo kouř z kouřovacích hlásičů — Am-241)
- **Různé absorbující materiály:** papír (0,1 mm), hliník (1 mm), olovo (2 mm), voda (5 cm)
- **Měřítko** (na měření vzdálenosti zdroje)
- **Poznámkový blok a kalkulačka**

**Bezpečnost:**
- Minimální manipulace se zdrojem
- Pracovat s dlouhými kleštěmi
- Bez krmení — zdroj NESMÍ být požitý
- Vypracovat pod dohledem učitele

---

## 3. Postup

### Fáze 1: Detekce záření (10 minut)

1. **Detektor** zapněte a poznamenejte **základní počet** (background — bez zdroje).
2. **Radioaktivní zdroj** (pomocí kleští) umístěte blízko detektoru.
3. **Zaznamenejte** počty impulsů za 1 minutu (nebo 10 sekund × 6).
4. **Zdroj odstraňte** — měl by se baseline vrátit k počáteční hodnotě.

| Měření | Počet impulsů za 1 min | Pozorování |
|---|---|---|
| Background (bez zdroje) |  |  |
| Se zdrojem (vzdálenost ~2 cm) |  |  |
| Bez zdroje (znovu) |  |  |

### Fáze 2: Závislost na vzdálenosti (20 minut)

Zdroj pomalu oddalujte od detektoru a měřte intenzitu.

```
Zákon inverzní čtverce: I ∝ 1/d²

Když se vzdálenost zdvojnásobí, intenzita se zmenší na 1/4.
```

| Vzdálenost d (cm) | Počet impulsů za 10 s | I (impulsy/s) | 1/d² |
|---|---|---|---|
| 1 cm |  |  |  |
| 2 cm |  |  |  |
| 3 cm |  |  |  |
| 4 cm |  |  |  |
| 5 cm |  |  |  |

**Ověření:** Měl by být lineární vztah mezi I a 1/d²?

### Fáze 3: Absorpce záření (15 minut)

Různé materiály umisťujte **mezi zdroj a detektor** a měřte intenzitu.

| Absorbující materiál | Tloušťka | Počet impulsů za 10 s | I (impulsy/s) | Útlum (%) |
|---|---|---|---|---|
| Bez materiálu (baseline) |  |  |  | 0 |
| Papír | 0,1 mm |  |  |  |
| Hliník | 1 mm |  |  |  |
| Olovo | 2 mm |  |  |  |
| Voda | 5 cm |  |  |  |

**Útlum (%)** = (I_baseline − I_s_mat.) / I_baseline × 100%

**Pozorování:**
- Papír **zablokuje** alfa záření (slabé).
- Hliník/voda **částečně utlumí** beta a gama.
- Olovo **nejlépe stíní** gama záření.

## 4. Analýza

### Zákon inverzní čtverce

Vynesete graf:
- **Vodorovná osa:** 1/d² (cm⁻²)
- **Svislá osa:** I (impulsy/s)

Měla by to být **přímka** — ověření fyzikálního zákona.

### Penetrační schopnost

Která záření prošla kterými materiály?

---

## 5. Pozorování a bezpečnost

1. **Jaké záření vydával váš zdroj?** (Hádejte na základě absorpce.)
2. **Praktické aplikace:** Lékařská diagnostika (RTG, CT), sterilizace, geologie (datování hornin).
3. **Nebezpečí:** Dlouhodobá expozice záření → rakoviny, mutace, genetické škody.
