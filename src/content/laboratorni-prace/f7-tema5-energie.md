# Laboratorní práce: Ověřování zákona zachování energie

## Podtéma: Přeměny mezi gravitační potenciální energií a kinetickou energií

**Cíl:** Prakticky ověřit zákon zachování mechanické energie: **součet potenciální a kinetické energie zůstává konstantní** (v nepřítomnosti tření).

---

## 1. Úvod

Energie existuje v mnoha formách: potenciální energia (závisí na poloze), kinetická energia (závisí na pohybu), tepelná energia… Během pohybu se tyto formy energie navzájem přeměňují, ale **celková energie zůstává konstantní** (pokud není ztráta třením).

Během experimentu budete:
- **Měřit** výšku a tíhu tělesa (potenciální energia)
- **Měřit** rychlost pádu (kinetickou energii)
- **Počítat** energií v různých fázích pohybu
- **Ověřit** zákon zachování energie

---

## 2. Pomůcky

**Základní pomůcky:**
- Hladká nakloněná rovina (výška min. 1 m; ideálně 1,5 m) nebo vysoká věž/most
- Kuličky či malá tělesa různých hmotností (50–200 g)
- Metr nebo svinovací metr (přesnost na 1 cm)
- Váhy (přesnost ≥ 1 g)
- **Papír pro měření času dopadů** (alternativa: použít video analýzu)
- Kalkulačka

**Pokud má budova schody či střechu:**
- Měření pádu z různých výšek (1 m, 2 m, 3 m…)

---

## 3. Postup

### Fáze 1: Příprava (10 minut)

1. **Těleso:** Zvažte kulku či těleso (hmotnost m).
2. **Měřítko:** Připravte měřítko pro měření výšky.
3. **Lokace:** Vyberte si místo s největší bezpečnostní volností (venkovní prostor, bez lidí pod sebou).

### Fáze 2: Měření z různých výšek (30 minut)

#### Metoda A: Přímé měření doby pádu

1. **Z výšky h₁** (např. 1 m) **pusťte těleso**.
2. **Změřte dobu pádu t₁** (stopkami nebo videokamerou — přesnost je klíčová).
3. **Opakujte 3 krát**, aby jste zjistili průměr.
4. **Postup opakujte** pro výšky h₂, h₃ (2 m, 3 m atd.).

| Výška h (m) | Čas pádu t₁ (s) | Čas pádu t₂ (s) | Čas pádu t₃ (s) | Průměr t (s) | Rychlost v = √(2gh) (m/s) |
|---|---|---|---|---|---|
| 1 m |  |  |  |  |  |
| 2 m |  |  |  |  |  |
| 3 m |  |  |  |  |  |

**Poznámka:** Z kinematiky **v = √(2gh)**, kde g ≈ 10 m/s².

#### Ověření času pádu

Ze vzorce **h = ½ g t²** vypočítejte teoretický čas:

```
t_teoretické = √(2h / g)

Příklad: h = 1 m, g = 10 m/s²
t = √(2 × 1 / 10) = √0,2 ≈ 0,45 s
```

Porovnejte s měřeným časem.

### Fáze 3: Výpočet energií (15 minut)

#### Gravitační potenciální energia (v počátečním bodě)

```
Ep = m · g · h

Kde:
- m = hmotnost (kg)
- g = 10 N/kg
- h = výška (m)
```

#### Kinetická energia (v okamžiku dopadú)

```
Ek = ½ m v²

Kde:
- v = rychlost (m/s) = √(2gh)
```

#### Ověření zákona zachování

V počátečním bodě: Ep_počátek + Ek_počátek = Ep_počátek + 0

V okamžiku dopadu: Ep_dopad + Ek_dopad = 0 + Ek_dopad

Měly by být oba součty **přibližně stejné**.

| Výška h (m) | Hmotnost m (kg) | Ep_počátek (J) | Ek_dopad (J) | Součet (J) | Odchylka (%) |
|---|---|---|---|---|---|
| 1 |  |  |  |  |  |
| 2 |  |  |  |  |  |
| 3 |  |  |  |  |  |

**Odchylka (%)** = |Ep_počátek − Ek_dopad| / Ep_počátek × 100%

## 4. Pozorování a analýza

1. **Je zákon zachování energie potvrzený?** Jaké jsou odchylky?
2. **Jak by se výsledky změnily, kdyby bylo tření?** (Např. papírová kulka vs. ocelová.)
3. **Praktické příklady:** Kde vidíte přeměnu gravitační potenciální energie na kinetickou? (Sjíždka na tobogánu, kyvadlo, lyžařský sjezd…)
4. **Bezpečnost:** Proč musí být rychle jedoucí auto více opatrné než pomalé? (Kinetická energia.)
