# Laboratorní práce: Působení těles a deformace

## 1. Úvod

**Co budeme dělat:**  
V této práci si procvičíme, jak fyzické síly způsobují změny tvaru těles — **deformaci**. Budeme měřit, jak se různé materiály deformují pod různou silou, a zjistíme, které deformace jsou trvalé a které se vrátí do původní podoby. Budeme pracovat s pružinami, gumičkami, plastelínou a papírem.

**Proč je to důležité:**  
Deformace těles nás obklopuje všude — od pružiny matrace, která se stlačí naším tělem, až po trvalé ohyby kovů v továrnách. Porozumění deformaci nám pomůže pochopit, jaké síly potřebujeme, abychom něco zlomili, natáhli nebo stlačili.

---

## 2. Pomůcky

- **Pružina nebo gumička** (délka min. 10 cm, přiměřená tuhost)
- **Plastelína** (1 malý kus, cca 50–100 g)
- **Papír nebo dřevo** (jeden list A4, jedna dřevěná lať, cca 30 cm)
- **Různé závaží** (mince, kolíčky, kníčky — 10–500 g)
- **Měřítko nebo posuvné měřidlo** (přesnost alespoň 0,5 cm)
- **Stojánek nebo upínač** (na zavěšení pružiny)
- **Tužka a papír** (na záznam dat)
- **Digitální váha** (volitelně, pro přesnost)

## 3. Postup

### Pokus 1: Pružná deformace — zatěžování pružiny

1. **Příprava:**
   - Pružinu upevněte svisle na stojánek.
   - Změřte její **původní délku** (bez zátěže): L₀ = _____ cm
   - Označte si značkou, kde se pružina začíná.

2. **Měření:**
   - Postupně přidávejte závaží (mince po kusech, kníčky — každý po ~50 g).
   - Po každém přidání čekejte 5 sekund, aby se pružina ustálila.
   - Změřte novou délku: L₁, L₂, L₃, L₄, L₅
   - Vypočítejte **prodloužení**: Δl = L − L₀

3. **Tabulka:**

| Hmotnost (g) | Síla (N) | Délka (cm) | Prodloužení Δl (cm) |
|--------------|----------|------------|---------------------|
| 0            | 0        | L₀ = ___   | 0                   |
| 50           |          |            |                     |
| 100          |          |            |                     |
| 150          |          |            |                     |
| 200          |          |            |                     |

4. **Zajímavé pozorování:**
   - Všechna závaží odstraňte.
   - Pružina se vrátila do původní délky? **ANO / NE**
   - Pokud se **nevrátila** — tím se pružina **trvale poškodila** (překročili jsme mez pružnosti!).

---

### Pokus 2: Nevratná deformace — plastelína

1. **Příprava:**
   - Vezměte kus plastelíny a **změřte jeho délku**: cca L = _____ cm (např. válec)
   - Poznamenejte si barvu a tvar.

2. **Zatížení:**
   - Položte plastelínu na stůl.
   - Postupně na ni pokládejte závaží (každých 30 sekund přidejte dalších 100 g).
   - Po každém zatížení **pozoruji**:
     - Změnila se barva?
     - Jakou má nový tvar?
     - Je plastelína teplejší?

3. **Konec pokusu:**
   - Všechna závaží sundejte.
   - Plastelína se vrátila do původního tvaru? **ANO / NE**
   - Závěr: plastelína prošla **nevratnou deformací** = změnila se trvale.

---

### Pokus 3: Ohyb papíru a dřeva

1. **Papír (list A4):**
   - Položte list na dva podstavce (např. knihy) ve vzdálenosti cca 20 cm.
   - Postupně přidávejte závaží uprostřed (mince do pohára).
   - Po jaké hmotnosti se papír **přerazí**?
   - Hmotnost při zlomení: m = _____ g

2. **Dřevo (lať, délka 30 cm, tloušťka ~1 cm):**
   - Stejný pokus s dřevěnou latí na stejné vzdálenosti.
   - Po jaké hmotnosti se dřevo **zlomilo**?
   - Hmotnost při zlomení: m = _____ g

3. **Pozorování:**
   - Který materiál byl tužší — papír nebo dřevo?
   - Papír se při ohybu **vrátil do tvaru**? (pružná deformace)
   - Dřevo se při ohybu vrátilo? (nebo zůstalo ohnuté?)

## 5. Vysvětlení

### Deformace a její typy

**Deformace** = trvalá nebo dočasná změna tvaru nebo rozměrů tělesa vlivem vnější síly.

#### Pružná (elastická) deformace
- Těleso se **vrátí do původního tvaru**, když síla přestane působit.
- Příklady: pružina, gumička, trampolína, tenisový míč
- Fyzika: **Hookeův zákon** — prodloužení je **přímo úměrné** síle: **Δl = k · F**
  - Δl = prodloužení (m)
  - F = síla (N)
  - k = koeficient tuhosti (N/m)

#### Plastická (nevratná) deformace
- Těleso se **NEVRÁTÍ** do původního tvaru, když síla přestane.
- Příklady: plastelína, olovo, některé plastické materiály, měkký kov
- Fyzika: Molekuly se trvalě posunou na nové místa, již se nevrátí.

#### Křehká deformace
- Těleso se **zlomí** nebo **praskne** bez viditelného ohybu.
- Příklady: sklo, keramika, křída, suchý papír
- Fyzika: Materiál selhá náhle, bez varovného signálu.

### Meze tuhosti

Každý materiál má **mez pružnosti** — síla, nad kterou se chování změní z pružného na plastické.

## 6. Rozšíření

1. **Porovnání pružin:**
   - Vezměte dvě různé pružiny (tužší a měkčí).
   - Kterou z nich prodloužily menší závaží?
   - Závěr: Tuha pružina má **vyšší koeficient tuhosti** (k).

2. **Měření tepla během deformace:**
   - Během pokusu s plastelínou **měřte teplotu** (teploměr).
   - Plastelína se zahřála?
   - Závěr: Nevratná deformace **uvolňuje energii ve formě tepla**.

3. **Cyklická zatížení:**
   - Pružinu zatěžujte a odlehčujte **opakovaně** (20–30 krát).
   - Měří se délka po každém cyklu.
   - Oslabuje se pružina? (zmůrá-li se)
   - Závěr: Cyklické zatížení může vést k **únavě materiálu**.

4. **Porézní materiály:**
   - Vezměte houbu (plastickou či gumovou).
   - Deformuje se podobně jako plastelína?
   - Jak se liší od plastelíny?
   - Závěr: V deformaci může hrát roli i **vzduch v pórech**.

5. **Váš oblíbený experiment:**
   - Vezměte nějaký material, který vás zajímá (guma, textil, plast), a vyzkoušejte jeho deformaci.
   - Jaký je jeho chování — pružné, plastické nebo křehké?
