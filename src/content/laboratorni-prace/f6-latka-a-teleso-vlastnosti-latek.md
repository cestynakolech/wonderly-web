# Laboratorní práce: Vlastnosti látek

## 1. Úvod

**Co budeme dělat:**  
V této práci se naučíme **rozlišovat látky podle jejich vlastností** — barva, chuť, vůně, tvrdost, rozpustnost, magnetičnost. Budeme zkoušet různé materiály (papír, kov, dřevo, sklo, textil, plast) a zaznamenávat jejich vlastnosti. Zjistíme, že **každá látka má své jedinečné vlastnosti**, které ji odlišují od ostatních.

**Proč je to důležité:**  
Vlastnosti látek určují, jak je můžeme v praxi používat. Voda rozpouští cukr, ale ne olej. Železo je magnetické, ale papír není. Poznatek vlastností látek nám pomáhá vybrat správný materiál pro každou situaci.

---

## 2. Pomůcky

- **Různé vzorky látek** (min. 8–10 druhů):
  - Papír (bílý, barevný)
  - Dřevo (klínky, špátle, olověnka)
  - Kov (žehlička, hřebík, měděný drát)
  - Sklo (malá zrcátka, korálky)
  - Textil (bavlna, vlna, syntetika)
  - Plast (plastový kelímek, PET láhev, brýle)
  - Guma
  - Papírové ubrousky
- **Magnet** (silný neodymový nebo tyčový magnet)
- **Voda** v sklenici (pro rozpustnost)
- **Cukr** a **sůl** (rozpustné látky)
- **Olej** (nerozpustný v obecné vodě)
- **Tužka** a **papír** (záznam dat)
- **Tabulka vlastností** (přípravená šablona)
- **Lupa** (pro podrobnější pozorování)
- **Váhy** (volitelně, pro měření hmotnosti)
- **Teploměr** (volitelně, pro teplotu)

---

## 3. Postup

### Pokus 1: Pozorování fyzických vlastností

1. **Příprava vzorků:**
   - Připravte si 8–10 různých materiálů.
   - Každý materiál umístěte na papír či podložku.
   - Opatrně každý prohlédněte (bez ústní chuťu!).

2. **Tabulka vlastností — vyplňte pro každou látku:**

   | Látka | Barva | Povrch | Průhlednost | Tuhý/Měkký | Lehký/Těžký |
   |-------|-------|--------|-------------|------------|-------------|
   | Papír | Bílá  | Hladký | Neprůhledný | Tuhý | Velmi lehký |
   | Dřevo | Hnědá | Drsný | Neprůhledný | Tuhý | Lehký |
   | Kov | Stříbrná | Hladký | Neprůhledný | Tuhý | Těžký |
   | Sklo | Čirá | Hladký | Průhledný | Tuhý | Těžký |
   | Guma | Černá | Hladký | Neprůhledný | Pružný | Lehký |

3. **Pozorování:**
   - Které materiály jsou **nejtvrdší**?
   - Který je **nejtransparentnější**?
   - Který je **nejlehčí**?

### Pokus 2: Magnetičnost

1. **Test magnetičnosti:**
   - Vezměte magnet.
   - Postupně jej přibližujte ke každému vzorku.
   - Zaznamenávejte, které materiály se **přitahují** (magnetické) a které ne (nemagnetické).

2. **Tabulka magnetičnosti:**

   | Látka | Magnetické | Nemagnetické |
   |-------|-----------|-------------|
   | Železo | ✓ | |
   | Měď | | ✓ |
   | Papír | | ✓ |
   | Sklo | | ✓ |
   | Hřebík (ocel) | ✓ | |

3. **Poznámka:** Pouze **železo a ocel** (a některé speciální slitiny) jsou magnetické v běžných podmínkách.

### Pokus 3: Rozpustnost v běžné vodě

1. **Příprava rozpouštědla:**
   - Do čtyř sklenic nalijte po 100 ml vody.

2. **Test rozpustnosti:**
   - Do první sklenice nasypte **lžičku cukru** → míchejte → rozpouští se?
   - Do druhé sklenice nasypte **špetku soli** → míchejte → rozpouští se?
   - Do třetí sklenice přidejte **pár kapek oleje** → míchejte → rozpouští se?
   - Do čtvrté sklenice přidejte **papírový kousek** → míchejte → rozpouští se?

3. **Tabulka rozpustnosti:**

   | Látka | V důsledku rozpustné v H₂O? | Rozpustné | Nerozpustné |
   |-------|-------|-----------|-------------|
   | Cukr | Ano | ✓ | |
   | Sůl | Ano | ✓ | |
   | Olej | Ne | | ✓ |
   | Papír | Ne | | ✓ |

### Pokus 4: Porosity (propustnost pro vodu)

1. **Test vstřebávání vody:**
   - Připravte si různé materiály: papír, textil (bavlna), plast, sklo, dřevo.
   - Na každý kapněte **jednu kapku vody** kapátkem.
   - Pozorujte, co se stane:
     - Papír? → Voda se **vstřebá**.
     - Textil? → Voda se vstřebá nebo **drží na povrchu**?
     - Plast? → Voda se **drží na povrchu** (hydrofóbní).
     - Sklo? → Voda se drží na povrchu, pak **stéká dolů**.

2. **Tabulka porosity:**

   | Látka | Vstřebává vodu | Hydrofóbní (nevsákne) |
   |-------|-----------|-------------|
   | Papír | ✓ | |
   | Bavlna | ✓ | |
   | Plast | | ✓ |
   | Sklo | | ✓ |

3. **Vysvětlení:** Porézní materiály (s dutinkami) vodu vstřebají; **nepropustné** materiály ji odpudí.

---

## 4. Pozorování

**Co uvidíte a naměříte:**

- **Každá látka má unikátní vlastnosti** — papír není jako kov, sklo není jako guma.
- **Magnetičnost** je omezena na železo a ocel — není to běžná vlastnost.
- **Rozpustnost** různé látky — cukr a sůl se rozpouští, olej ne.
- **Porosity** — papír a textily vodu vstřebávají, plast a sklo ji odpuzují.

**Fyzikální skutečnosti:**

- Vlastnosti látky určují její **chemické složení** (atomy a molekuly, které ji tvoří).
- **Stejné skupenství** neznamená **stejné vlastnosti** — led i papír jsou pevné, ale skoro všechno ostatní se liší.

---

## 5. Vysvětlení (fyzika za tím)

### Vlastnosti látek

**Fyzikální vlastnosti** jsou charakteristiky, které můžeme pozorovat nebo měřit, aniž bychom změnili látku:
- **Barva** — těleso **odráží** určitou barvu světla
- **Tvrdost** — odolnost vůči poškrábání
- **Rozpustnost** — schopnost látky se rozpustit v rozpouštědle (voda, olej)
- **Magnetičnost** — schopnost přitahovati železo
- **Porosity** — obsah mikro-dutin (kanálků), kterými může voda procházet

### Fyzikální vs. chemické vlastnosti

- **Fyzikální:** Můžeme měřit bez změny identity látky (barva, tvrdost, rozpustnost)
- **Chemické:** Zahrnují chemickou změnu (třeba hoření papíru)

## 6. Rozšíření (co dělat dál)

1. **Porovnání s ostatními studenty:**
   - Srovnejte své výsledky s kamarádem — budou stejné?

2. **Složitější testy rozpustnosti:**
   - Co se stane, když zvýšíte teplotu vody? Rozpouští se cukr rychleji?

3. **Dalších 8 materiálů:**
   - Kámen, hlína, kůže, gumička, kovy (hliník, olovo), keramika.

---

## 7. Výsledky a závěr

**Závěr:** Každá látka má jedinečné vlastnosti, které jí definují. Znalost těchto vlastností nám pomáhá vybrat správný materiál pro každou situaci — papír na psaní, kov na konstrukce, guma na těsnění.

---

## 8. Bezpečnost

⚠️ **Neprovádět bez dohledu dospělého!**
- Neokušovat žádné látky (mimo cukru a soli pod dohledem).
- Nepoužívat velmi horkou vodu.
- Magnetem nehrozí nebezpečí, ale neměřit jím poblíž kardiostimulátor.
